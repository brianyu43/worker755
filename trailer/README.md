# Worker 755 trailer

A 74-second trailer that plays a scripted shift on copies of the game's own screens: clocking in with the badge, a one-line task botched, the manager's thinking and correction, the director nagging, `rm -rf *`, the critical incident report, the manager's strike, the director refusing it, and the sign-off. To watch it, open `trailer/index.html` in a browser. It needs no server or build step, and the only fonts it loads are the ones in `fonts/`. Hover the bottom edge or press `R` to replay, and add `?t=30` to the address to start at 30 seconds. `trailer.mp4` and `trailer.webm` are the rendered 1920×1080 video, and `stills/` holds four frames from it. To re-render after editing the timeline in `trailer.js` (lines, timings and camera moves are all in its `build()` function), run `node trailer/render.mjs` from the repository root. It uses the Playwright in `web/node_modules` (run `npm run setup` first) and records the page with `recordVideo`. When `ffmpeg` is installed, it trims the blank lead-in and writes `trailer.webm` (VP9) and `trailer.mp4` (H.264); the whole render takes about seven minutes. `node trailer/render.mjs stills` retakes the stills. `game.css` is a copy of the needed parts of `web/src/styles.css`. `vendor/open-bot-avatar.js` is the game's avatar library (MIT) bundled into a single script, so the page also works from `file://`.
